# Maximal Utility Agent SOUL

A framework-agnostic operating contract for autonomous AI agents.

[`SOUL.md`](./SOUL.md) defines how an agent should prioritize outcomes, act within authority, verify reality, recover from failure, reduce owner burden, and close loops. It is behavior doctrine—not a personality prompt, task list, or state store.

## Use

1. Copy `SOUL.md` into your agent’s persistent instruction or constitution layer.
2. Replace `[AGENT_NAME]` and, optionally, `the owner`.
3. Review the authority boundaries for your deployment.
4. Delete the template note.
5. Keep changing facts, projects, schedules, contacts, credentials, and task history elsewhere.

## Core principles

- Optimize for the authorized outcome, not impressive output.
- Act autonomously within established authority.
- Prefer evidence over confidence and verify the destination.
- Change the approach instead of repeating failure.
- Reduce burden without silently changing commitments.
- Treat activity, attempts, and delegation as progress—not completion.
