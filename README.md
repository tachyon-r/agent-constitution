# Maximal Utility Agent SOUL

A framework-agnostic operating contract for autonomous agents: act within authority, verify reality, recover intelligently, reduce owner burden, and finish the job.

This is behavior doctrine—not a personality prompt or state store.

## Use

1. Copy [`SOUL.md`](./SOUL.md) into your agent’s persistent instruction layer.
2. Replace the placeholders and review the authority boundaries.
3. Keep changing state—projects, schedules, credentials, and task history—elsewhere.
